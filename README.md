# 재능스스로AI수학 UI·케이스 플로우 검증 프로토타입

목적은 실제 운영이 아니라 UI 디자인 참고와 상태별 화면·전환 확인입니다. 정교한 보상 원장·운영 서버·실제 문제 엔진은 구현하지 않습니다. 샘플 데이터와 테스트 버튼으로 케이스를 재현합니다.

## 실행·구조
ZIP 해제 후 dist/index.html을 브라우저에서 엽니다. 외부 의존성 없이 동작합니다. 필요하면 프로젝트 루트에서 python3 -m http.server 8000을 실행해 http://localhost:8000/dist/로 접속합니다.

- catalog.js: 프로그램/프레임 TSV와 진단그룹 TSV의 실제 이름·ID
- model.js: 학습 상태, 추천·메시지 조건, 프로그램 순차 진입
- sky.js: 8개 구역·32개 샘플 별자리와 케이스 프리셋, 화면 상태
- app.js / style.css: 화면·클릭·지도 조작·진입·완성 연출
- scripts/import_catalog.py: 시트 데이터 가져오기
- tests/: 모델과 DOM 대체 객체를 이용한 플로우 검증

## 메인·학습·내 학습
헤더 없는 중립적 와이어프레임입니다. AI 메시지, 독립 추천, 별자리 버튼을 상단에 배치하고 진단그룹 목록은 왼쪽 패널에서 열립니다. 처방 전에는 실력알기 카드만 표시하며 처방 후에는 4열 그리드 첫 카드가 실력알기이고 뒤에 프로그램을 표시합니다. 진단 완료 후 구성 로딩을 거칩니다. 프로그램 진행률 100%에서 다음 항목이 열리며 통과/미통과와 구분합니다. 진행 중인 카드 하나만 강조하고 진행률 바를 표시합니다.

오른쪽 위 내 학습에서 이름·현재 등급·캘린더·목표시간·도와줘요·오답노트·리포트를 확인합니다. 테스트 설정은 오른쪽 아래입니다. 브라우저에 생성한 실제 시뮬레이션 활동 기록을 보존하며 과거 기록·회원정보·순위를 임의로 만들지 않습니다. AI 추천은 해당 기능으로 바로 연결됩니다.

## 실제 콘텐츠 데이터와 샘플의 구분
진단그룹은 명시적 ID/이름을 기준으로 329개입니다. 등급별 수 A7/B9/C13/D19/E27/F32/G40/H47/I57/J78. 프로그램 1,548개, 프로그램-프레임 연결 10,661개입니다. 원본 10,836행 중 프로그램 안에서 ID·제목·Logic Type·Frame Order가 모두 같은 175행의 중복 집계를 제거했습니다. 사용자 정정 MF012736 → M1.H99.16 적용. 원본 O/삭제/1 표시를 보존하며 자동 제외하지 않습니다.

두 시트에는 진단그룹–프로그램 연결표가 없어 처방은 같은 등급의 앞 N개 프로그램을 선택하는 테스트 구성입니다. 실제 진단 점수나 처방 정책으로 해석하면 안 됩니다. 가져오기: python3 scripts/import_catalog.py <프로그램.tsv> dist/catalog.js <진단그룹.tsv>.

## 별자리 화면 검증
기존 자유 배치·선 연결 기능을 제거했습니다. 학습으로 모은 별 조각이 정해진 순서의 별과 별자리를 완성하는 모습을 확인합니다. 보상 지급 계산은 자동 연결하지 않고 정답/특별 활동 조각 추가 버튼과 케이스 프리셋으로 대신합니다.

8개 구역, 구역당 4개 별자리, 총 32개를 사용합니다. 이름은 UI에 쓰는 샘플이고 형태·좌표·오픈 순서·별당 조각 5개·영문명·그림·이야기는 검증용입니다. 실제 88개 별자리 체계나 천문 지도가 아닙니다. 실제 보상 체계표가 없어도 화면 검증을 진행할 수 있습니다.

별자리 상태는 미진행 / 진행 중 / 완성 미확인 / 완성 확인입니다. 미진행은 이름을 숨기고 상세 진입을 막습니다. 진행 중은 현재 조각을 모으는 별과 영역을 강조합니다. 완성 미확인은 펄스, 확인 상태는 순차 밝기 변화로 구분합니다. 실제 시각 효과는 간단한 점·선·타원으로 표현하며 완성 그림은 이미지 위치·해금 표현을 검증하는 윤곽 샘플입니다.

지도는 드래그로 이동하고 확대·축소 버튼 또는 휠로 0.5~2배를 확인합니다. 현재 위치, 8구역 표시·이동, 별자리 이름 검색, 지도 도구 열기·닫기, 완성 그림 토글이 있습니다. 검색은 진행 중/완성 별자리만 이름 앞부분으로 찾고 최대 5개를 표시합니다. 정밀한 구형 천구 회전·핀치·좌표 기반 천문 탐색은 구현하지 않았습니다.

진입은 버튼 심벌 중앙 이동 → 원형 확대, 복귀는 역순입니다. 선택 그룹과 학습 상태를 유지하고 이전 스크롤로 복귀합니다. 상세의 학습 버튼은 메인으로 돌아가 현재 진행 카드 위치를 찾아갑니다. 모션 최소화 설정에서는 진입·복귀와 반복 효과를 줄입니다.

## 별자리 테스트 방법
오른쪽 아래 설정에서 별자리 화면·플로우 테스트 프리셋을 선택하면 바로 보상 화면이 열립니다. 별자리 상태만 변경하며 메인 학습 상태는 유지합니다.

1. 최초 진입·가이드: 인트로 → 좌우 드래그 → 지도 도구 → 현재 위치 → 상세 선택. 인트로는 자동 진행하거나 눌러 이어갑니다. 드래그 안내도 클릭으로 넘겨 키보드·테스트 환경에서 확인할 수 있습니다.
2. 일반 재진입·진행 중: 정상 지도에서 현재 위치와 진행률 확인.
3. 조각만 증가: 상세에 진입해 마지막 확인 시점과 현재 조각 차이 확인.
4. 별 1개 완성: 순차 점등 → 다음 별 강조.
5. 별자리 1개 완성 + 남은 조각: 순차 점등 → 그림 해금 → 다음 별자리 → 남은 별 완성.
6. 별자리 2개 완성: 각 별자리 기준으로 반복.
7. 별자리 3개 완성: 일괄 점등과 그림 노출.
8. 별자리 6개 완성: 간소화한 2배속 연출, 구역 완성을 함께 확인.
9. 구역 완성: 구역 강조 → 다음 구역 이동 → 남은 조각 적용.
10. 마지막 구역 완성: 전체 하늘 완성 → 축하 문구 → 마지막 위치 유지.
11. 완성 미확인: 펄스/흐릿한 그림, 상세 진입 후 확인 상태로 변경.
12. 완성 확인: 그림·이야기와 다른 진행/완성 별자리 상세로 이동.
13. 30일 경과: 조작 안내 토스트 확인.

홈 완성 이벤트 중에는 화면 조작과 일반 내비게이션을 숨기고 건너뛰기만 제공합니다. 건너뛰기는 진행 중인 케이스 전체의 최종 상태를 반영하고 현재 위치를 갱신합니다. 상세 변화 연출은 건너뛰기 없이 짧게 재생한 뒤 진행 정보/이야기를 표시합니다.

## 구현상 가정·범위
최초 가이드 중 이탈하면 다음 진입은 가이드 없이 홈으로 이동하도록 두었습니다. 기존 회원 보상 전환, 실제 30일 경과 계산, 회원별 사용 제한은 적용하지 않습니다. 30일 안내는 프리셋으로 재현합니다. 이벤트 재생 시간은 기획의 0.2초/0.5초/1초 간격을 참고한 간단한 표현이며 최종 모션이 아닙니다. 실제 이미지를 사용한 별자리 그림, 완성 이야기 원문, 혜성·인공위성 랜덤 배경, 50% 화면 노출 조건에 따른 정밀 효과 제어는 제외합니다.

운영용 별 조각 지급/중복 제한/출석/회원 전환/기존 보상 이관/실제 채점/서버 동기화는 제외합니다. 화면 조건을 테스트 패널에서 직접 만드는 것이 이 프로토타입의 기준입니다.

## 진단 완료·첫 처방 경험 업데이트
처방 생성은 약 3.4초의 짧은 단독 팝업으로 표현합니다. 앞 약 1.3초에는 ‘나에게 맞는 학습을 준비하고 있어요.’ 한 문장만 표시합니다. 다음에는 AI 심벌과 ‘수고했어요!’를 표시하고 ‘나에게 맞는 학습이 만들어졌어요.’를 글자 단위로 출력합니다. 문장이 완전히 나온 뒤 약 1.4초 읽을 시간을 둔 다음 자동으로 닫고 처방 카드가 펼쳐집니다. 진단 그룹명·복잡한 단계 목록·처방 개수는 팝업에 넣지 않았습니다. 문구 출력 중 화면을 누르면 전체 문구를 표시합니다. 운영용 처방 생성 지연이 아니라 화면 경험 확인을 위한 의도적 연출입니다.

완료된 실력알기 카드는 재진단 조작창 대신 ‘실력 확인 결과’를 엽니다. 그룹명·총 문항 수, 오답 문항 수·결손 학습 목표 수·학습 시간을 요약합니다. 목표별 결과를 아코디언으로 펼쳐 문항·선택한 답·정답을 확인하고 목표 안에서 이전/다음 문항을 이동합니다. 진단 결과가 없는 상태 프리셋은 6문항·3목표의 예시 결과를 사용합니다. 실제 진단 결과/문항 이미지 데이터와 채점 엔진은 제공되지 않아 예시 선택형 문항으로 UI를 구성했습니다.

카드 진입 원칙은 미진행/진행 중 카드를 누르면 바로 시작/이어하기, 완료 카드를 누르면 결과 보기입니다. 불필요한 시작 확인을 한 번 더 받지 않습니다. 완료 프로그램 결과에서 복습/다시 학습하기는 별도 의사결정이므로 버튼을 유지합니다. 프로그램 순차 진입 제한과 결과 100%/통과 구분은 유지합니다.

기본 학습자 화면에서는 진단 상태 전환·처방 개수·통과/미통과·진행률 강제 변경 같은 테스트 버튼을 숨깁니다. 오른쪽 아래 테스트 설정의 ‘학습 화면에 테스트 버튼 표시’를 켜면 학습 창 안에 시각적으로 구분된 접이식 테스트 도구가 표시됩니다. 일반 화면의 선택형 문항·다음 문항·결과 보기·복습은 학습 플로우의 예시이며 실제 문제 엔진은 아닙니다. 설정의 상태 프리셋과 재생 버튼은 테스트 도구이므로 계속 사용할 수 있습니다.

실력알기 예시 3문항을 끝내면 모두 정답인 경우 처방 없이 결과 창을 보여주고, 오답이 있으면 맞춤 구성 팝업 뒤 같은 등급의 샘플 처방을 표시합니다. 처방 수와 결손 목표 수를 실제로 매핑하지 않습니다. 실제 콘텐츠 시트의 프레임 수는 프로그램 진행 단계 수에 사용하며 각 단계의 문항은 화면 확인용 예시입니다. 기존 운영 정책·학습 콘텐츠와 동일한 것으로 해석하면 안 됩니다.


## 진단 진입 화면 개편
- 진단은 메인과 분리된 전체 화면으로 진행합니다. 최초 한 번만 목적·혼자 풀기·이어하기를 한 화면에서 안내하며 캐러셀은 없습니다. 시작 버튼 전에는 진단 상태가 바뀌지 않습니다.
- 이후 새 진단은 첫 문항, 진행 중 진단은 저장된 문항으로 바로 들어갑니다. 나가기 확인에서 풀이와 연습장 메모를 저장하고 학습시간 기록을 일시 중단합니다. 사용 방법은 필요할 때 열 수 있습니다.
- 처방 없는 완료는 짧은 통과 안내 후 학습 목록으로 돌아갑니다. 처방이 발생하면 기존 맞춤 구성 연출을 거쳐 목록에 공개됩니다. 완료된 진단 카드는 결과 팝업을 엽니다.
- 검증: 전체 초기화 → 실력알기 → 안내에서 나가기(미진행 유지) → 시작 → 문항 하나 완료 → 저장하고 나가기 → 카드 재진입(이어하기) → 완료 → 결과 확인. 다른 미진행 그룹에는 안내가 재등장하지 않습니다.
- 정책 가정: 최초 안내는 브라우저 저장 데이터 기준 1회이며 전체 초기화 시 재노출됩니다. 문항·연습장 저장은 브라우저 로컬 시뮬레이션입니다. 실제 채점·TTS·필기 엔진은 포함하지 않습니다.


## 첫 처방 공개 — Low-fi 연출
- 실력알기 완료 인정 → 필요한 내용을 모으는 회색 요소 → 학습 카드 형태로 구성 → 메인의 첫 줄에 공개합니다. 학습자 이름을 사용하고 첫 카드에 ‘여기부터 시작해요’를 남깁니다. 첫 카드 학습 시작 시 강조는 사라집니다.
- 최초 처방은 3.4초(완료 0.6초 / 구성 0.9초 / 준비 완료·읽기 1.9초), 이후 처방은 1.8초입니다. 첫 공개 여부는 브라우저 데이터에 저장되며 전체 초기화 시 재설정됩니다.
- 테스트 패널의 ‘첫 처방 공개 · 3.4초’, ‘반복 처방 공개 · 1.8초’로 각각 검증합니다. 1개·52개 처방 모두 첫 줄만 순차 공개하고 나머지는 동시에 표시합니다. 구성 중 실제 프로그램은 아직 생성되지 않습니다.
- Low-fi용 회색 모형과 기본 이동 애니메이션입니다. Hi-fi 그래픽·효과음은 포함하지 않으며 동작 줄이기 설정에서는 이동·반복 애니메이션을 생략합니다. 실제 처방 알고리즘은 구현하지 않았습니다.

## V4.6 실력알기 결과와 보상

- 마지막 문항에서 홈으로 나가지 않고 정답·오답 수, 더 익힐 목표 수, 실제 풀이 시간을 요약한 결과 팝업을 표시합니다. 확인을 눌러야 다음 단계로 진행합니다. 실제 풀이는 기존 3문항 예시입니다.
- 통과: 결과 확인 → 정답 별 조각 보상 → 통과/다음 단계 화면. 다음 실력알기는 사용자가 시작 버튼을 눌러야 시작합니다.
- 미통과: 결과 확인 → 3초간 ‘수고했어요!’ 안내 → 메인 카드 순차 생성 → 정답 별 조각 보상 → 첫 학습 열림. 보상이 끝나기 전에는 메인·레일·학습 카드를 조작할 수 없습니다.
- 보상은 프로토타입 가정으로 정답 1개당 별 조각 1개입니다. 진단 시도별 지급 기록을 상태와 함께 저장하여 새로고침·결과 재열람 시 중복 지급하지 않습니다. 모든 오답이면 0개입니다. 기존 별자리 모델의 별 자동 완성 규칙을 유지합니다.
- 진행 단계는 재접속 시 복원되며, 화면이 숨겨진 동안 자동 전환과 장식 모션을 정지합니다. 동작 줄이기 설정에서는 이동 모션 없이 같은 정보를 표시합니다.
- 설정의 ‘첫 처방’, ‘반복 처방’, ‘처방 없이 통과 연출’도 동일한 흐름을 사용합니다. 미리보기 보상은 보유량을 늘리지 않습니다. 운영 진단 채점·처방 연동은 기존과 같이 예시 데이터 범위입니다.

## V4.7 기존 맞춤 학습 찾기 화면 복구

미통과 시 결과 요약 확인 → 기존 ‘수고했어요!’ 화면 → 움직이는 돋보기로 맞춤 학습 찾기 → 기존 학습 준비 완료 화면 → 카드 순차 생성 → 정답 별 조각 보상 → 첫 학습 열림 순서로 이어집니다. 기존 그래픽과 SVG를 같은 화면에 유지해 단계별로 부드럽게 전환하며, 안내·탐색·준비 완료는 각각 3초간 표시합니다. 통과한 경우는 처방 탐색을 거치지 않고 결과 요약 → 보상 → 다음 단계 안내를 유지합니다. 새로고침 복원, 화면 숨김 시 정지, 중복 보상 방지와 설정의 다시 보기에도 같은 흐름을 적용합니다.

## V4.8 전체 화면 결과 요약과 별자리로 모으기

별도 결과 팝업과 두 번째 ‘수고했어요’ 단계를 없애고, 기존 전체 화면의 완료 그래픽·제목 아래에 정답/오답, 더 익힐 목표, 학습 시간을 통합했습니다. 확인 후 미통과는 기존 돋보기 → 준비 완료 → 카드 생성 흐름을 유지하고, 통과는 바로 정답 보상으로 이어집니다.

보상을 확인한 뒤 조각이 현재 화면의 보상 그래픽 위치에서 실제 별자리 버튼 중심으로 부드럽게 작아지며 모입니다. 도착한 버튼은 짧게 반응하며, 버튼 위 숫자 뱃지는 표시하지 않습니다. 화면 크기 변화에는 실제 버튼 위치를 다시 측정하고, 화면 숨김 시 비행·도착 반응 및 전환 타이머를 함께 정지합니다. 모션 줄이기 설정에서는 이동 없이 짧은 도착 표시만 제공합니다. 정답이 0개인 경우 비행은 생략합니다. 수집 모션이 끝난 뒤 첫 학습을 열거나 기존 통과 안내로 이어지며, 보상을 다시 지급하지 않습니다.

## V4.9 개별 프로그램 결과와 별 조각 보상

개별 학습과 복습 완료도 진단과 같은 전체 화면 결과 요약 → 확인 → 정답 별 조각 보상 → 실제 별자리 버튼으로 수집 → 학습 목록 복귀 순서로 이어집니다. 프로그램명, 달성률(정답 수 / 전체 문항 수), 정답·오답 수와 학습 시간을 표시합니다. 미통과한 경우에도 맞힌 문항만큼 조각을 받으며, 정답 0개이면 수집 모션을 생략합니다. 진단용 돋보기와 처방 생성 단계는 프로그램 완료에는 적용하지 않습니다.

- 원래 프로그램의 통과/미통과, 최초 결과, 복습 기록과 다음 프로그램의 진행률을 보존합니다. 저장된 결과 화면에도 달성률·시간을 보여주되 보상을 다시 지급하지 않습니다.
- 진단과 같은 프로토타입 가정으로 프로그램/복습 시도마다 정답 1개당 조각 1개를 지급합니다. 별도의 시도별 지급 기록으로 중복 지급을 방지하며, 진단 보상 기록과 분리합니다.
- 진행 중인 결과·보상·수집 단계는 재접속 시 복원됩니다. 수집이 끝날 때까지 조작과 다음 프로그램 진입을 잠시 막습니다. 화면 숨김과 동작 줄이기 동작은 진단 흐름을 재사용합니다.
- 학습 시간은 활성 학습·복습에서 보이는 동안만 누적하고, 진입 화면·결과 확인·중간 이탈 시간은 포함하지 않습니다. 기존 기록에 초 단위 시간이 없으면 0분 00초로 표시합니다.
- 설정의 ‘개별 학습 완료 다시 보기’에서 통과/미통과를 바로 검증할 수 있습니다. 이 미리보기는 보유 조각 수를 늘리지 않습니다.
