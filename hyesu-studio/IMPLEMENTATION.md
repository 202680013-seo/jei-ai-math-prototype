# JEI Math · 디자인 프로토타입

## 현재 관리자 UI
하단에는 한국어/영어, 시나리오, 디자인, 아이콘 형태의 초기 시연 상태 복귀만 표시합니다.
별도 컬러 편집·시연 모드·컬러1/2 토글은 제거했습니다. 기존 테마 계산 API는 저장된 시안 호환을 위해 유지합니다.

디자인모드에 진입하면 화면 클릭이 계속 요소 선택으로 동작합니다. 선택을 마쳐도 학습 모드로 자동 전환하지 않습니다. `window` capture에서 pointer/click/Enter/Space를 처리해 기존 document의 학습 이벤트로 전달하지 않습니다. 종료 버튼 또는 Escape로 디자인모드를 끝내면 원래 학습 인터랙션이 복원됩니다.

속성: 요소 선택 후 배경·텍스트·테두리·크기·굵기·모서리, 이 요소/같은 종류, 상태별 스타일.
테마: Primary / Secondary / Neutral / 기능 색상으로 묶음. 서체는 나눔스퀘어, 나눔스퀘어라운드, Pretendard 3개만 제공.
시안: 디자인 전체 저장·적용·삭제, JSON 입출력, 디자인 초기화.
안내 문구는 요소를 선택하지 않은 상태의 한 줄로 제한했고 대비는 미달 시에만 표시합니다. 편집기 제목 영역을 드래그해 위치를 옮길 수 있습니다.

## 색상 반영
- HEX `input` 이벤트에서 유효한 색상을 즉시 반영하며 Enter/blur가 필요하지 않습니다.
- 메인 컬러는 입력 HEX 그대로 주요 버튼과 브랜드 색상에 적용합니다. OKLCH로 생성한 11단계와 hover/강조 배경을 함께 연결하되 명시적으로 편집한 역할은 유지합니다.
- `--theme-*`, `--status-*` 역할과 개별 스타일 규칙을 CSS로 적용합니다. 기존 inline 변수 위에 역할 override를 두어 고정 색상에 가려지던 값을 연결합니다.
- 학습 카드 `img.active-card-art`의 원본 SVG를 유지하고 브랜드 색상 stop만 메인 컬러로 치환합니다. 흰색과 투명도·그라데이션 구조는 보존합니다. 시나리오 재렌더링·시안 전환·색상 복원에도 적용합니다.
- 완료/재학습 아이콘은 각 역할이 편집되었을 때 의미와 형태를 유지하며 색상을 연결합니다.
- 기능색과 뉴트럴은 브랜드와 독립적으로 편집합니다.

## 시나리오
기존 11개 상태를 먼저 표시하고 진단 시작 / 처방·완료 연출 / 진도·프로그램 설정 / 별자리 / 멘토·추천 / 고급 설정을 접는 섹션으로 구성합니다. 기존 버튼과 input 노드를 옮기므로 상태 변경·진도 제어 핸들러는 그대로입니다. 중복 안내문·검증 설명·사용할 수 없는 원본 다운로드 링크를 제거했습니다.

## 변경 파일
- index.html: 별도 컬러 편집 UI 로드 제거, 시나리오 표시 어댑터 추가.
- versions/v71/report.js: 하단 컨트롤 간소화와 리셋 SVG 아이콘.
- admin/design-studio.js, .css: 모드 입력 분리, 편집 UI 재구성, 즉시 HEX, 색상 역할 및 SVG 연결.
- admin/design-store.js: 허용 서체 3종 및 이전 설정 마이그레이션.
- admin/scenario-view.js: 시나리오 표시 어댑터.
- fonts/NanumSquareRound{R,B,EB}.woff, NanumSquareRound-LICENSE.txt: 라운드 폰트 로컬 포함. 기존 Pretendard와 나눔스퀘어 파일/라이선스 유지.
- tests/design-store.test.cjs: 서체 제한과 이전 설정 마이그레이션 검사.

기술 스택은 빌드 없는 HTML/CSS/JavaScript를 유지하며 새 라이브러리를 추가하지 않았습니다. app.js, model.js와 진단·학습 콘텐츠는 변경하지 않았습니다. 학습 상태와 디자인 localStorage는 독립입니다.

## 검증
- JavaScript 구문 검사 및 색상/저장소 테스트 통과.
- 색상 엔진: 1,010개 sRGB 왕복, 11,110개 단계의 명도·대비, gamut과 hue 보존 검사.
- 디자인 저장소: undo/redo, 시안·JSON·재시작 복원, 학습 키 독립, 입력 검증, 허용 서체와 기존 설정 이관.
- 브라우저: 반복 카드 클릭과 Enter가 학습 모달을 열지 않음. 모달 답안 반복 클릭도 선택/진도를 변경하지 않음. 디자인 종료 후 원래 카드 학습 진입 정상.
- HEX 입력 후 blur 없이 실제 버튼 배경 rgb(37,99,235)와 SVG 소스 #2563eb 일치 확인. 개별 완료 카드 HEX도 즉시 일치 확인.
- 나눔스퀘어라운드 실제 font-family 및 document.fonts 로드 확인.
- 390px/768px iframe의 편집 패널과 하단 컨트롤 확인. 실제 iPad/Safari 장비 검증은 수행하지 않음.

## 위계·투명도·테두리 확장
- 테마 그룹 내 순서는 강조/텍스트 → 경계 → 표면/배경 기준으로 정렬합니다.
  - Primary: 메인 컬러 → 버튼 텍스트 → Hover → AI 추천 테두리 → AI 추천 배경.
  - Secondary: 보조 컬러 → 말풍선 텍스트 → 말풍선 테두리 → 말풍선 배경 → 강조 배경.
  - Neutral: 제목 → 본문 → 보조 텍스트 → 테두리 → 카드·팝업 → 보조 배경 → 페이지.
  - 기능: 완료 → 정답 → 오답 → 재학습 → 시작 전 → 잠금 아이콘 → 잠금 배경.
- 모든 색상에 0~100% 불투명도를 제공하며 0%는 투명입니다. HEX6/HEX8/#RGB/#RGBA/transparent 입력을 지원하고 체크무늬 컬러칩으로 알파를 표시합니다.
- 투명한 배경은 부모의 색상으로 치환하지 않고 실제 투명값을 유지합니다. 요소 전체의 opacity를 바꾸지 않아 텍스트까지 함께 흐려지지 않습니다.
- 테두리 두께는 선택한 요소 또는 같은 종류에 px 값(0~40, 소수점 포함)으로 지정합니다. 테두리 스타일이 none일 때 두께를 지정하면 solid를 추가합니다.
- 알파와 두께는 undo/redo, 자동 저장, 시안 및 JSON 왕복에 포함합니다.
- AI 추천 테두리·배경, 멘토 말풍선 텍스트·테두리·배경을 역할로 추가했습니다. 메인 컬러 변경 시 연결되며 명시적 개별 역할 편집은 우선합니다.
- 새로고침은 Lucide refresh-cw 원본 SVG를 사용하며 dist/assets/icons/에 소스와 라이선스를 포함합니다. npm 런타임 의존성은 추가하지 않았습니다.
- 추가 모듈: admin/design-colors.js. 추가 테스트: tests/design-colors.test.cjs.
- 검증: 알파 혼합, 투명값/HEX8, 두께 저장·JSON복원·취소/재실행 자동 검사 통과. 브라우저에서 배지 0% 배경, 카드 50% 배경/4px 테두리, 메인 #2563eb의 AI 추천 연동, 말풍선 #97e4bf 60%의 실제 computed CSS 확인. CSS의 소수점 두께는 저장되며 실제 표시 픽셀은 기기의 배율에 따라 반올림될 수 있습니다.
